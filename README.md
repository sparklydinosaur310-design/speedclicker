# speedclicker

This project is a fun 2d game inspired by cookie clicker.

## About the project
**What is this project?**

In this game, you click to get speed and when you have enough speed you can challenge NPCs for rewards. In this game there is an achievements tab, main tab, challenge tab, collection tab and a decor tab.

**Why did I make this project?**

I made this project because I remembered how addictive cookie clicker was and I wanted to create another web game that is similar to cookie clicker.

## Tech Stack

This project was built using:

-HTML

-CSS

-JavaScript

-Json

-Jsx

## Features

Some of the main features include:

-**Logging in** : You can create an account and verify your account in your gmail.

-**Leaderboard** : There is a leaderboard in this game so you can compare yourself with other users.

-**Pixel Art** : After defeating an NPC, you can get a creature. All of the creature pixel arts were hand drawn by code.
